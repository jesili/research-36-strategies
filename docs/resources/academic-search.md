## 安全与密码学专用

- **[IACR ePrint](https://eprint.iacr.org/)**：密码学论文预印本，[eprint.iacr.org](https://eprint.iacr.org/)
- 安全方向直接看 S&P、USENIX Security、CCS、NDSS 等**会议官网**

## 使用建议

- 不要把 ResearchGate、博客、网盘当成论文元数据和版本判断的最终依据
- 学校图书馆已购买的数据库应通过校园网或学校授权的校外访问方式使用

## 学术访问路径（按优先级）

1. **校园网**：在校内优先通过学校网络访问已订购数据库。
2. **学校官方 VPN / WebVPN / 图书馆校外访问**：校外访问订阅资源时优先使用学校提供的统一身份认证渠道。
3. **出版社开放版本**：查找作者主页、机构仓储、[arXiv](https://arxiv.org/)/[IACR ePrint](https://eprint.iacr.org/) 等合法公开版本。
4. **DOI / 论文题目检索**：找不到 PDF 时先定位 DOI 和正式出版页面，再判断是否存在开放版本。
5. 对 Google Scholar 等学术搜索工具，如所在网络无法稳定访问，应遵守学校网络管理规定和所在地法律法规，使用学校认可的网络服务。

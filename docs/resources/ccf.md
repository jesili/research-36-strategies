# CCF 推荐国际学术会议和期刊目录

## 是什么

CCF 推荐国际学术会议和期刊目录是计算机领域非常重要的导航工具。2026 年 CCF 已正式发布**第七版**目录，仍按领域组织并分 A/B/C 类。

## 怎么用

它最适合回答：**"这个领域有哪些主流 venue"**。

!!! warning "重要提醒"
    不要把 "CCF A" 机械理解为每一篇论文都比 B/C 更值得读；目录是入口，不是替代学术判断的排名器。

## 信息安全方向建议熟悉

会议（至少熟悉）：

- IEEE S&P
- USENIX Security
- ACM CCS
- NDSS
- 密码学：CRYPTO、EUROCRYPT、ASIACRYPT

期刊：

- TDSC、TIFS 等

具体级别和归类以 CCF 最新官方目录为准。

# 安徽大学自然科学导向性期刊目录

## 是什么

学校目录与 CCF 目录用途不同：

| 目录 | 用途 |
| --- | --- |
| CCF 推荐目录 | 计算机学科共同体的 venue 推荐 |
| 安大自然科学导向性期刊目录 | 与学校科研评价、成果认定等制度相关 |

做投稿规划时**两份目录都应知道**，但不要只根据"级别"倒推研究问题。

## 成果分类

学校自然科学成果分 **A+、A、B、C、D** 五类。

信息安全 A+ 的代表性期刊/会议包括（举例）：

- 期刊：TDSC、TIFS、Journal of Cryptology
- 会议：INFOCOM、NSDI、CCS、EUROCRYPT、IEEE S&P、CRYPTO、USENIX Security、NDSS、ASIACRYPT

!!! note "最终依据"
    实际认定请始终以**学校最新文件和相关管理办法**为准。

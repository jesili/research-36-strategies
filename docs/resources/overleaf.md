# Overleaf

在线编辑、编译和协作 LaTeX 文档，适合从官方模板快速开始论文写作。

## 适合什么时候用

第一次写论文时，推荐直接把会议/期刊官方 LaTeX 模板上传到 Overleaf，**先学会改内容**而不是从空白文件搭模板。

**30 分钟内至少会**：

- 章节（section）
- 公式（equation）
- 图片（figure）
- 表格（table）
- label / ref
- cite
- BibTeX
- 编译错误定位

## 最小使用流程

上传会议或期刊官方模板，先确认能正常编译；再依次掌握章节、公式、图片、表格、交叉引用、文献引用和错误定位。多人协作时统一主文件和编译方式。

## 常见问题

当项目变大，或者需要 Git、Codex/AI、Python 作图脚本和论文文件在同一个工程中协同时，本地 [VS Code + LaTeX](vscode-latex.md) 更方便。

两者不是二选一：**先 Overleaf 入门，再逐渐掌握本地环境。**

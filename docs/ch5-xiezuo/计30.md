# 第30计：Overleaf 和本地 VS Code 怎么选？

> **一句话：选择摩擦更小的环境，并确保项目始终可备份、可编译。**

## 为什么

写作环境影响协作、版本和自动化，但不存在对所有项目都最好的选择。把时间花在工具争论上，或在项目中途频繁迁移，都会增加与论文内容无关的风险。

## 怎么选

- **刚入门、多人协作**：Overleaf 最省心
- **项目变大、需要 Git/AI/本地脚本联动**：VS Code + LaTeX Workshop 更灵活

两者不是二选一：**先 Overleaf 入门，再逐渐掌握本地环境。**

## 一个反例

多人只在 Overleaf 同时改同一段，没有稳定版本；或本地装了复杂环境却没有锁定依赖，换电脑后无法编译。工具看似先进，协作风险反而更高。

## 应该怎么做

短论文或早期协作用 Overleaf 快速开始，定期下载或 Git 备份；项目变大、需要脚本生成图表和本地工具时转向 VS Code。无论哪种方式，都统一主文件、编译引擎、参考文献工具和目录规则，提交前在干净环境完整编译。

## 自检

- [ ] 合作者是否都能稳定编译？
- [ ] 项目是否有独立备份和版本历史？
- [ ] 图表脚本与论文是否容易联动？
- [ ] 工具迁移是否会丢失评论、版本或依赖？

## 记住

> 最好的环境不是功能最多，而是让协作与复现最少出错。

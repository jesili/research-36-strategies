# 第35计：投稿之前到底应该检查什么？

> **一句话：投稿前不是只查格式，而是最后一次检查整条证据链。**

## 为什么

写作接近结束时，人会对熟悉内容失去敏感，容易漏掉不一致的数字、过强 claim、缺失 baseline 和匿名信息。格式合规只是最低条件。

## 核心检查

- 问题能否一句话说清
- 贡献是否明确
- 最强 baseline 是否覆盖
- claim 是否都有证据
- 引用是否真实
- 图表是否清楚
- 匿名/伦理/模板/页数是否合规

## 一个反例

正文声称“显著优于所有方法”，表格却缺少最强 baseline；摘要数字与实验表不一致；补充材料还保留作者路径。单项都可能影响可信度或直接导致拒稿。

## 应该怎么做

建立 claim—evidence 对照表，逐条核对正文、图表和附录；重新运行关键结果或检查生成链；逐条打开引用；让未参与写作的人按审稿人视角阅读。最后再检查匿名、伦理、模板、页数、文件和提交系统要求。

## 自检

- [ ] 每个主要 claim 是否有充分证据？
- [ ] 数字、符号和术语是否全文一致？
- [ ] 最强 baseline 与公平设置是否覆盖？
- [ ] 匿名、伦理和提交文件是否完全合规？

## 记住

> 投稿前最后一次认真检查，往往比再润色十遍句子更有价值。

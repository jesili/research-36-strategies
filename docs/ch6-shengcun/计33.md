# 第33计：应该怎么向导师汇报科研进展？

> **一句话：汇报进展要汇报判断变化，而不是动作清单。**

## 为什么

“看了十篇、跑了三天”只能说明投入，导师仍不知道项目到了哪里、哪里需要帮助。有效汇报应让对方快速理解证据、问题和下一步选择。

## 固定模板

> 做了什么 → 得到什么 → 出现什么问题 → 我的分析 → 下一步

!!! note "重点"
    不要只汇报"看了几篇、跑了多久"，要汇报**获得了什么判断**。

## 一个反例

把一周日志逐条念完，最后才说实验结果与预期相反，却没有分析可能原因，也没有明确希望导师判断什么。

## 应该怎么做

开头先给一句当前结论；用最少的图表展示关键证据；区分已确认事实、当前解释和待验证猜想；列出两三个下一步及各自代价。至少带一个需要讨论或判断的问题，让汇报可以形成决策。

## 自检

- [ ] 与上次相比，哪个判断改变了？
- [ ] 证据能否支持当前结论？
- [ ] 遇到的问题是否已有自己的分析？
- [ ] 希望导师提供信息、资源还是方向判断？

## 记住

> 好汇报让下一步更清楚，而不是证明这一周很忙。

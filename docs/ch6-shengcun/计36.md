# 第36计：科研最重要的长期习惯是什么？

> **一句话：让读、想、做、写、讲、改形成长期闭环。**

## 为什么

科研能力很少来自一次冲刺。工具、模型和热点会变，真正可迁移的是发现问题、形成判断、设计证据和复盘错误的能力。长期习惯的目标不是每天完成固定动作，而是持续推进认识。

## 基本循环

> 读 → 想 → 做 → 写 → 讲 → 改

读文献形成问题，思考得到假设，实验产生证据，写作暴露逻辑缺口，汇报接受质疑，再据此修改判断。任何一环长期缺失，循环都会退化。

## 一个反例

只收藏和阅读，从不动手验证；或只跑实验，不记录为何这样设计。看起来一直忙，却没有可积累的判断、代码、笔记和经验。

## 应该怎么做

保持稳定但可持续的节奏，每周记录“本周哪个判断被支持、否定或修改”；关键失败也写入复盘；定期整理文献、代码和结果，让产物可重新使用。用阶段目标约束工具和热点，而不是随它们不断换方向。

## 自检

- [ ] 最近的阅读是否转化为问题或实验？
- [ ] 实验是否改变了某个判断？
- [ ] 失败是否被记录并形成经验？
- [ ] 我的产物三个月后还能否理解和复用？

## 记住

> 工具会过时，判断、执行与复盘能力会复利。

# 第32计：听完别人汇报不知道问什么怎么办？

> **一句话：好问题来自检查假设、证据和边界，而不是展示自己懂得多。**

## 为什么

听汇报时想不到问题，通常是只跟随内容，没有主动判断。提问不必追求“高深”，一个准确的澄清或证据问题就能推进讨论。

## 三层问题

先问基础问题：

- 哪里没懂？
- 哪个假设可能不成立？
- 哪个结论证据不足？

再升级：

- 有没有更简单解释？
- 换场景是否成立？
- 攻击者更强会怎样？

还可以追问：这个实验具体排除了哪种替代解释？结论在哪些条件下会失败？

## 一个反例

为了发言而问报告中已经明确回答的问题，或用很长的背景包装一个与主线无关的细节。问题数量有了，讨论却没有推进。

## 应该怎么做

边听边记三列：没懂、不同意、想延伸。先复述自己的理解，再提出一个边界清楚的问题；涉及批评时指出具体假设或证据，不评价人。若答案已在前文，先承认可能遗漏并请对方定位。

## 自检

- [ ] 问题针对对象、假设、方法还是证据？
- [ ] 是否能用一两句话说清？
- [ ] 回答后会改变什么判断？
- [ ] 是否尊重对方并允许自己理解有误？

## 记住

> 提问的价值在于推进共同判断，不在于增加存在感。

# 科研思维

> 研究对象 · 研究问题 · 贡献 · 方法 · 证据

三十六计是**怎么做事**的操作手册；而"科研思维"回答的是更底层的问题：
**科研到底在做什么？一篇论文究竟新在哪里？怎样判断一个方向该继续还是止损？**

这一篇不放进 36 计，因为它不是某一步操作，而是贯穿始终的判断标准。
暑期课最有价值的部分，其实就沉淀在这里。

| 主题 | 一句话 |
| --- | --- |
| **研究到底是什么？** | 看见一个值得研究的问题，并用可信证据支持或否定 |
| **研究问题从哪里来？** | 从已有工作的"不够"处，或反常现象中长出 |
| **一篇论文新在哪里？** | New Problem / Understanding / Method / Evaluation / System |
| **什么叫贡献？** | 让领域比它多知道一点，且可被独立验证 |
| **什么叫证据？** | 能支持 claim、可复现、可被反驳的，才叫证据 |
| **如何判断"为了论文而论文"？** | 没有真问题，或无法被验证，就是在凑 |
| **何时继续、何时止损？** | 以"是否推进当前判断"为准，不是动作量 |

!!! info "怎么用"
    这一篇适合**反复读**。每读一篇论文、每做一次实验，都拿这几个问题回头对照一次。
    用得多了，它会长成你们组自己的"科研直觉"。

## 研究到底是什么

一句话：**看见一个值得研究的问题，提出可被验证的猜想，用足够可信的证据支持或否定它。**

- **对象**：你研究的是什么（系统、现象、问题）。
- **问题**：这个对象上有一个什么"不够好 / 没人解决 / 没被理解"的地方。
- **方法**：你用什么手段去得到答案。
- **证据**：用什么结果支撑或推翻你的判断。

!!! tip "科研判断，而不是科研动作量"
    读了几篇论文、跑了几次实验，本身不是贡献。
    有没有推进对某个问题的判断，才是。

## 研究问题从哪里来

研究问题很少凭空出现，通常长在这两处：

1. **已有工作的"不够"**：读论文时问"它为什么没做 X？是做不到，还是没意识到？"那个"没意识到"常常就是问题。
2. **反常现象**：实验里出现一个解释不了的结果、或一个"应该成立却失败"的现象，值得停下来追根。

!!! warning "别从"我要发论文"出发"
    从"我想发论文"反推问题，很容易凑出一个假问题。
    先有真问题，再谈能不能成文。

## 一篇论文新在哪里

判断一篇论文的价值，先看它属于哪种"新"：

| 类型 | 含义 | 举例 |
| --- | --- | --- |
| **New Problem** | 提出一个没人系统研究过的问题 | 把 A 领域的现象搬到 B 领域并定义清楚 |
| **New Understanding** | 对已知现象给出新的解释/分析 | 解释某个长期被"当作黑箱"的现象 |
| **New Method** | 提出新的方法/算法/技术 | 改进模型、设计新机制 |
| **New Evaluation** | 新的评测方式/基准 | 发现旧 benchmark 不公平，提出新 benchmark |
| **New System** | 把想法做成可用的系统 | 把原型工程化为可运行系统 |

> 一篇好论文往往不止一种"新"。读论文时先问它属于哪一类，再问"这个新，是否真的成立"。

## 什么叫贡献

贡献 = **让领域比它之前多知道一点，并且这一点可以被独立验证。**

两个必要条件：

- **有增量**：去掉这篇，领域会不会少点什么？
- **可验证**：别人拿着你的方法/数据/代码，能不能复现或反驳？

!!! warning "空贡献"
    如果去掉这篇论文，没人会少知道什么——那它就没有贡献，只有篇幅。

### 方法不是贡献

!!! warning "用了什么 ≠ 新在哪里"
    技术是 LLM、方法是微调、实验跑了三个数据集，这些都不自动构成贡献。
    **贡献回答的是：以前不知道或做不到什么，现在因为这项研究知道了或做到了什么？**

“我们使用区块链、属性加密或强化学习”只是在描述技术选择。只有当这个选择解决了明确问题，并且证据表明它比已有方案带来了新的能力、认识或边界时，才可能形成贡献。

## 一个完整案例：拆开一项安全研究

下面是一个经过简化的教学案例。它不强调具体模型名称，而是演示怎样把论文摘要还原成可判断的研究链条。

```text
研究对象：具有长期记忆能力的智能体
        ↓
研究问题：单独看似无害的信息，在长期记忆中组合后，
          是否可能形成新的攻击路径？
        ↓
贡献：定义并验证一种跨记忆片段组合产生的攻击现象，
      说明逐条过滤不足以覆盖这种风险
        ↓
方法：构造分散式攻击输入，在多种模型与记忆系统上测试，
      并与现有过滤方法对比
        ↓
证据：攻击成功率、跨模型结果、消融实验、
      现有防御失效条件与失败案例
```

读这个案例时，注意五个部分不能互相替代：对象不是问题，方法不是贡献，结果数字也不天然就是证据。只有当证据能支撑“这种现象存在、在什么条件下存在、现有方法为何不足”时，研究链条才闭合。

!!! example "换成你正在读的论文"
    合上原文，依次写出对象、问题、贡献、方法、证据。如果某一格只能抄技术名词，说明那一部分还没有真正读懂。

## 什么叫证据

证据不是"数字好看"，而是：

- **支撑 claim**：每个 claim 都要能被某个图/表/分析对应上。
- **可复现**：别人按你的设置能得到相近结果。
- **可被反驳**：好的证据允许"在什么条件下不成立"，而不是永远正确。

!!! info "对照 claim"
    读论文时，把每个 claim 和支撑它的证据画线对应；对不上的 claim，就是论文最薄弱处。

## 如何判断"为了论文而论文"

出现以下信号，就要警惕是在"凑"：

- 说不清要解决什么**真问题**，只说"这个方向热门"。
- 贡献无法被独立验证，或复现条件含糊。
- 证据只是"数字高"，但说不清为什么高、在什么条件下成立。
- 换掉方法、数据或场景，结论就崩塌，说明没有抓到本质。

## 何时继续、何时止损

!!! tip "判断标准"
    以"**是否推进了当前判断**"为准，而不是以做了多少动作为准。

- **继续**：新问题让旧判断被修正，或新证据让结论更可信。
- **止损**：连续一段时间，动作很多但没有推进任何判断；或关键假设被否定、反常结果无法解释时，及时回头，别硬扛。

!!! tip "及时止损不是失败"
    早一步发现方向走不通，省下的是一整个学期的时间。

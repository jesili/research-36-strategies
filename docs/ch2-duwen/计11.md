# 第11计：一篇论文到底要看到多深？

> **一句话：阅读深度由使用目的决定，不应平均分配。**

## 为什么

每篇都精读会耗尽时间，每篇都只看摘要又无法形成可靠判断。阅读深度不是对论文质量的评价，而是它与你当前任务的关系。

## 按用途分级

| 类型 | 看到什么程度 |
| --- | --- |
| 了解型 | 问题 + 贡献 |
| 相关工作型 | 方法 + 假设 + 差异 |
| 核心论文 | 算法、证明、实验、代码、附录 |

!!! note "原则"
    精读是稀缺资源，**不应平均分配**。

## 一个反例

为了“读完”一篇背景论文，逐行检查证明和代码；真正决定研究路线的核心论文反而只看了摘要。投入很多，却把精力用错了位置。

## 应该怎么做

阅读前先写用途。了解型回答问题和贡献；相关工作型还要比较假设、方法和差异；核心论文则检查算法、证明、实验、代码和附录。用途变化时可以升级深度，不必一次读完。

## 自检

- [ ] 我读它是为了了解、引用、比较还是复现？
- [ ] 当前深度足以支持这个用途吗？
- [ ] 哪些结论来自原文，哪些只是初步印象？
- [ ] 它值得进入核心论文清单吗？

## 记住

> 精读不是认真态度的表演，而是对关键证据的投资。

# 第1计：从哪里找论文？

!!! abstract "一句话原则"
    先找到**学术共同体认可的入口**，再找论文；而不是先在互联网里捞 PDF。
    找论文，是在为这个领域画一张地图。

## 为什么

刚入组时最容易犯的错误，是把"找论文"等同于"用搜索引擎找 PDF"。
ResearchGate 上的版本可能不是最终版、网盘里的文件可能缺图缺表、博客里的"解读"可能已经偏离原文。

学术论文的可靠来源，是**经过同行评议、由学术共同体维护的入口**：会议官网、期刊官网、DBLP、Google Scholar、IACR ePrint 等。
从这些入口进入，你拿到的才是可引用、可复现、可追溯的版本。

!!! tip "先地图，后 PDF"
    找论文不是找 PDF，而是在建立这个领域的地图。
    入口对了，后续的版本、作者、venue、引用关系才都可靠。

## 推荐顺序

按"你现在知道什么"选择入口，而不是无脑从某一个网站开始：

| 你目前知道 | 优先入口 | 说明 |
| --- | --- | --- |
| 一个明确题目/关键词 | Google Scholar、DBLP | 综合检索，再用 Cited by / References 扩散 |
| 一个大方向（如密码学） | 顶会目录、CCF 推荐目录 | 先看这个领域的主流会议 |
| 一篇代表论文 | 它的 **References / Cited by** | 顺藤摸瓜画文献树 |
| 密码学最新工作 | **IACR ePrint** | 密码学预印本，比正式会议更早 |
| 完全不知道关键词 | 从一篇近期好论文**反向提词** | 读它的标题/摘要，提炼 3–5 个英文词 |

!!! note "学校数据库"
    学校图书馆已购买的数据库（IEEE Xplore、ACM DL 等）应通过**校园网或学校授权的校外访问方式**使用，
    具体见 [学术搜索](../resources/academic-search.md)。

## 应该怎么做

假设你想研究 **"AI Agent 的权限控制 / 访问控制"**，但还不确定英文关键词。

1. 先用一个宽泛词在 Google Scholar 搜 `LLM agent`，挑 1–2 篇近期、引用较高、与你方向贴近的论文。
2. 打开它的标题与摘要，**提炼关键词**，第一次搜索可以从这几组开始：

     ```text
     "LLM agent authorization"
     "AI agent access control"
     "tool-use agent permission"
     ```

3. 把命中较好的几篇，按 **References（往前）/ Cited by（往后）** 扩散，形成一张小文献树。
4. 把真正值得读的几篇，用 [Zotero](../resources/zotero.md) 保存并打上 `ToRead` 标签。

> 不要一上来就下载 100 篇然后全部塞进 Zotero——那只是把垃圾转移了。

## 一个反例

!!! warning "常见错误"
     - **×** 用百度/通用搜索直接搜"智能体访问控制论文"，得到的是二手解读和过期 PDF。
     - **×** 看到 ResearchGate 上的 PDF 就当成正式版本，不核对作者、年份、venue。
     - **×** 一次搜 100 篇，全部下载，之后再也不打开。
     - **×** 关键词只用中文，或只用一个词，漏掉英文同义表达。

## 记住一句话

!!! quote "记住"
    找论文不是找 PDF，而是在建立这个领域的地图。

## 自检

- [ ] 论文能否追溯到会议、期刊或作者官方页面？
- [ ] 我是否记录了这个方向的核心 venue、作者和关键词？
- [ ] 新找到的论文能否放进已有文献关系图，而不是成为孤立 PDF？
- [ ] 保存前是否判断过它与当前问题的关系？

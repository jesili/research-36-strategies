# 第1计：从哪里找论文？

计算机领域先学会使用 **Google Scholar、DBLP、IEEE Xplore、ACM Digital Library**；密码学重点关注 **IACR ePrint**；安全方向还要直接看 **S&P、USENIX Security、CCS、NDSS** 等会议官网。

学校图书馆已购买的数据库应通过校园网或学校授权的校外访问方式使用。不要把 ResearchGate、博客、网盘当成论文元数据和版本判断的最终依据。

!!! tip "提示"
    相关官方入口见 [科研资源导航](../resources/index.md)。
